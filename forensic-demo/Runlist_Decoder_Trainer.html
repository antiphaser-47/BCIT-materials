Read the header byte

Every run in a run list starts with one header byte. It does not hold data — it tells you how wide the next two fields are.

Left nibble = how many bytes hold the starting cluster.

Right nibble = how many bytes hold the length.

On disk the order is length first, then start — the opposite way round from the nibbles. That swap is the trap.

Convert the relative offset

A run's starting cluster is stored as a difference from the previous run's start — so it can be negative. Get the sign wrong and you navigate off the end of the disk.

Step 1. Reverse the bytes. 78 EC → EC78

Step 2. Is the first hex digit 8 or higher? Then the number is negative.

Step 3. If negative, subtract the wrap value: 65,536 for 2 bytes, 16,777,216 for 3 bytes.
