Volatility commands for "The Fake Security Check"
=================================================
Open PowerShell or Command Prompt IN this folder, then type these directly.
The program (vol.exe) and the image (verification-required.elf) are right here.
If verification-required.elf is missing, right-click verification-required.zip -> Extract All first.

  .\vol.exe -f verification-required.elf windows.info
  .\vol.exe -f verification-required.elf windows.pstree
  .\vol.exe -f verification-required.elf windows.cmdline
  .\vol.exe -f verification-required.elf windows.netscan
  .\vol.exe -f verification-required.elf windows.registry.printkey --key "Software\Microsoft\Windows\CurrentVersion\Explorer\RunMRU"
  .\vol.exe -f verification-required.elf windows.consoles

Tip: add   > out.txt   to the end of a command to save its output to a file, e.g.
  .\vol.exe -f verification-required.elf windows.pstree > pstree.txt
